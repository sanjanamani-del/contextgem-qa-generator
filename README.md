# ContextGem Q&A Dataset Generator

Automated system for generating question-answer pairs from business documentation using ContextGem and GPT-5.

## Quick Start

1. Install dependencies: `pip install -r requirements.txt`
2. Set API key: `export OPENAI_API_KEY="your-key"`
3. Run: `python contextgem_qa_generator.py`

## Tools

- `contextgem_qa_generator.py` - Main Q&A generation system
- `qa_deduplication_cleaner.py` - Dataset cleaning and deduplication
